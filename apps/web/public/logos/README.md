# Sponsor logos

Drop the **official** logo files here as `{key}.svg`, taken only from each sponsor's press/brand kit
or from files shared by the organizers. Do not redraw, recolor or distort them.

Keys: `airbyte, cognee, superlinked, persona, guild, singlestore, arcee, firedrill, statsig, amplitude, aws, openai`

If a file is missing, `SponsorBadge` falls back to a neutral text pill with the sponsor's name.
